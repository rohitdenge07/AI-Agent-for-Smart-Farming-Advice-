# AI Agent for Smart Farming Advice

## Overview

AI Agent for Smart Farming Advice is an intelligent agricultural assistant built using IBM watsonx Orchestrate, and Retrieval-Augmented Generation (RAG).

The agent helps farmers make informed decisions related to crop cultivation, soil health, fertilizer recommendations, pest management, and sustainable farming practices.

## Features

* Crop Recommendation
* Soil Health Guidance
* Fertilizer Suggestions
* Pest and Disease Management
* Knowledge-Based Responses using RAG
* Farmer-Friendly Recommendations
* IBM Granite Powered AI

## Technology Stack

* IBM Cloud
* IBM watsonx Orchestrate
* Retrieval-Augmented Generation (RAG)
* GitHub Pages

## Knowledge Sources

The agent uses agricultural documents including:

* Rice Cultivation Handbook
* Wheat Cultivation Guide
* Pest Management Guide
* Soil Biology Guide

## Sample Questions

* Which crop is suitable for black soil?
* How can I control pests in rice?
* What fertilizer should I use for wheat?
* Suggest crops for the monsoon season.

## Project Objective

To provide small-scale farmers with reliable, knowledge-driven agricultural guidance that improves productivity, reduces risk, and promotes sustainable farming practices.
